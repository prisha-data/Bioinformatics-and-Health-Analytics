# Bellabeat Data Analysis Case Study 📈

### **Overview**
This project is a comprehensive data analysis of smart device fitness data to unlock growth opportunities for Bellabeat. It bridges my **Biotechnology** background with **Data Analytics** to analyze human health biometrics.

### **Tools Used**
* **Language:** R (tidyverse, ggplot2, lubridate)
* **Documentation:** RMarkdown & PDF
* **Platform:** Kaggle & GitHub

### **Key Files**
* `Bellabeat_Analysis_Code.R`: Full script for data cleaning, processing, and visualization.
* `Bellabeat_Report.pdf`: Final presentation of insights and strategic health recommendations.

### **Insights Gained**
By analyzing 30+ users' daily activity and sleep data, I identified a significant correlation between high sedentary time and reduced sleep quality. I proposed three data-driven marketing strategies focused on "active heart-rate" notifications to improve user wellness.

## Human Lung Cancer Gene Network Analysis
This project focuses on identifying key hub genes in human lung cancer using Cytoscape and Protein-Protein interaction networks.

## Project Contents
Inside this compressed folder, you will find the following core analysis files:
* **enrichment.KEGG.tsv:** The results of the KEGG pathway enrichment analysis, showing the biological pathways most relevant to the lung cancer gene set.
* **enrichment.Process.tsv:** A lsit of biological processes identified through functional enrichment.
* **hun_genes.xlsx..xlsx:** The primary dataset containing the human used for network construction.
* **string_hires_image.png:** High resolution export of protein-protein interaction(PPI) network generated via string database.
